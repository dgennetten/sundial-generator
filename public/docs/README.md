# Documents Directory

This directory should contain the following PDF files referenced in the About section:

## Required Documents:

1. **1980-12-SundialArticle.pdf** - Amateur Scientist column from December 1980 Scientific American
2. **SolarClockAd.pdf** - Advertisement for the solar clock
3. **AnalemmaIllustrationFromJune1985.pdf** - Hand-drawn instructional illustration
4. **SundialIllustrationFromJune1985.pdf** - Hand-drawn sundial illustration  
5. **Tabloid-sizeDial.pdf** - Example 11x17 inch sundial plotted with HP9872 plotter

## Instructions:

1. Add the PDF files to this directory
2. Run `npm run deploy-sftp` to upload them to the server
3. The links in the About card will then work correctly
