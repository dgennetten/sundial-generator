# DreamHost Simple Setup Guide

## 🎯 **DreamHost-Only Visitor Data Updates**

This setup runs entirely on DreamHost - no local server needed!

### **How It Works:**

1. **Cron Job on DreamHost**: Runs every night at 2 AM
2. **Generates Visitor Data**: Creates `visitor-data.json` file
3. **Your Built Dist**: Reads the JSON file directly
4. **No Local Server**: Everything happens on DreamHost

## 🚀 **Setup Steps**

### **Step 1: Deploy Scripts to DreamHost**

Copy these files to your DreamHost domain directory:
- `scripts/dreamhost-simple-visitor-update.js`
- `scripts/dreamhost-simple-cron.sh`

### **Step 2: SSH into DreamHost**

```bash
ssh YOUR_USERNAME@YOUR_DOMAIN.com
```

### **Step 3: Navigate to Your Domain Directory**

```bash
cd ~/YOUR_DOMAIN
```

### **Step 4: Configure the Cron Script**

Edit the cron script to match your DreamHost path:

```bash
nano scripts/dreamhost-simple-cron.sh
```

**Update this line with your actual path:**
```bash
PROJECT_DIR="/home/YOUR_USERNAME/YOUR_DOMAIN"
```

### **Step 5: Make Scripts Executable**

```bash
chmod +x scripts/dreamhost-simple-cron.sh
```

### **Step 6: Test the Script**

```bash
./scripts/dreamhost-simple-cron.sh
```

You should see output like:
```
✅ Visitor data updated successfully at [timestamp]
```

### **Step 7: Set Up the Cron Job**

```bash
crontab -e
```

**Add this line to run every night at 2 AM:**
```bash
0 2 * * * /home/YOUR_USERNAME/YOUR_DOMAIN/scripts/dreamhost-simple-cron.sh
```

### **Step 8: Verify the Cron Job**

```bash
crontab -l
```

You should see your cron job listed.

## 📊 **Customizing Visitor Data**

### **Edit the Visitor Data Generator:**

```bash
nano scripts/dreamhost-simple-visitor-update.js
```

**You can customize:**
- Visitor locations
- Visit counts
- Date ranges
- Add more visitors

### **Example Customization:**

```javascript
// Add more visitors
visitors: [
  {
    ip: '192.168.1.100',
    country: 'United States',
    countryCode: 'US',
    region: 'Colorado',
    city: 'Denver',
    lat: 39.7392,
    lon: -104.9903,
    timezone: 'America/Denver',
    firstVisit: sevenDaysAgo.toISOString(),
    lastVisit: now.toISOString(),
    visitCount: 15
  },
  // Add more visitors here...
]
```

## 📊 **Monitoring**

### **Check if Cron Job is Working:**

```bash
# View recent logs
tail -20 logs/cron.log

# Check if visitor data was updated
ls -la visitor-data.json

# View the visitor data
cat visitor-data.json
```

### **Manual Update:**

```bash
# Run the update manually
node scripts/dreamhost-simple-visitor-update.js
```

## 🔧 **Troubleshooting**

### **Common Issues:**

1. **"Permission denied"**
   ```bash
   chmod +x scripts/dreamhost-simple-cron.sh
   chmod 755 ~/YOUR_DOMAIN
   ```

2. **"Node.js not found"**
   - Contact DreamHost support to enable Node.js
   - Or use the full path: `/usr/local/bin/node`

3. **"Path not found"**
   - Verify your project directory path
   - Use `pwd` to get the correct path

4. **"Log file not writable"**
   ```bash
   mkdir -p logs
   chmod 755 logs
   ```
